## English (en)

**What's new in this version**

```text
Advanced settings (Settings → Advanced…): choose when to get a low-usage alert (below 10%, 20%, or 30% left) or turn alerts off.
Get notified when a limit that triggered a low-usage alert resets.
Optional usage pace (off by default): a limit that would run out before it resets at your current pace is marked on the card, with an estimate of when it runs out.
Shows the Claude spend limit when your organization sets one through a Claude apps gateway.
Reset countdowns on the card now line up.
Added Japanese, German, and Simplified Chinese interface options.
The Codex card shows available reset credits and the nearest known expiry when Codex provides them.
Settings makes clear that Claude's install and remove buttons manage usage capture, not Claude Code itself.
```

## 繁體中文 (zh-TW)

**此版本的新增功能**

```text
新增「進階設定」（設定 → 進階設定…）：低額度通知可選剩 10%、20%、30% 以下，或不通知。
發過低額度通知的額度重置時，會再通知你額度回來了。
可選的用量速度（預設關閉）：照目前速度會在重置前用完的額度，卡片上會標出來並估計何時用完。
公司透過 Claude apps gateway 設定花費上限時，顯示 Claude 花費上限。
卡片上的重置倒數改為對齊。
新增日文、德文與簡體中文介面。
Codex 卡片顯示重置券可用張數，以及有提供時最近已知的到期日。
設定中說明 Claude 的安裝／移除按鈕管理的是用量擷取，不會安裝或移除 Claude Code。
```

## 日本語 (ja)

**このバージョンの新機能**

```text
「詳細設定」を追加しました（設定 → 詳細設定…）：残量低下の通知を残り 10%・20%・30% 未満から選ぶか、オフにできます。
残量低下の通知が出た利用枠がリセットされると、あらためてお知らせします。
使用ペース（任意、初期設定ではオフ）：今のペースだとリセット前に使い切る利用枠をカードに表示し、使い切るまでの目安を示します。
組織が Claude apps gateway で利用額上限を設定している場合、Claude の利用額上限を表示します。
カードのリセットまでの時間表示をそろえました。
日本語、ドイツ語、簡体字中国語の表示に対応しました。
Codex が提供する場合、Codex のカードに使用できるリセット券の枚数と、最も早い有効期限を表示します。
設定画面で、Claude の導入／削除ボタンが扱うのは使用量の取得であり、Claude Code 本体ではないことを明記しました。
```
